# RobotGuideline image assets

This directory stores local image assets used by the RobotGuideline article.

This published subset contains the 28 raster assets actually referenced by
`RobotGuideline/edition-2/index.html`. It exists so Notion can import stable,
auditable copies of the images. Unreferenced working assets and textbook SVGs
are intentionally omitted; the 14 textbook diagrams are already attached to
their corresponding Notion chapters.

## Generated educational illustrations

- `joint-module-whole-and-exploded.png`: generated with the built-in image generation tool to show one generic rotary actuator as both an assembled unit and an exploded educational view.

These generated images are explanatory illustrations, not photographs of a named manufacturer's product.

Generation prompts:

- **joint-module-whole-and-exploded.png**: "Create a technical editorial illustration showing the same generic integrated rotary robot joint actuator twice: an assembled complete cylindrical module on the left and a precise exploded view on the right. Include housing, output bearing, reducer, frameless motor stator and rotor, encoder, driver board, seals and fasteners. Neutral metal materials, white studio background, no labels, no text, no logos."
